# Nova

Navegador ligero para Windows sobre Chromium: sin anuncios, sin rastreadores y con IA local.

- Bloqueo de anuncios y rastreadores (listas tipo uBlock), también en YouTube.
- Pack YouTube: calidad máxima, modo música, sin Shorts, modo sin distracciones, «No me gusta» visibles y SponsorBlock.
- Nova IA (Ctrl+J): resume videos y páginas en tu equipo, con WebGPU integrado u Ollama.
- Nova Wrapped: el tiempo que te devolvió cada mes, listo para compartir.
- Video flotante automático, mini reproductor, vista dividida, paleta de comandos (Ctrl+K).
- Importa favoritos e historial desde Chrome, Edge y Brave.

## Desarrollo

```bash
npm install
npm start
```

Instalador: `npm run dist` (queda en `dist/`). Publicar versión con actualización automática: `npm run release` con `GH_TOKEN` definido.
